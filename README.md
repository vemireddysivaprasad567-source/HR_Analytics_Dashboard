# HR Analytics Dashboard

## 📌 Project Overview
This project is an interactive HR Analytics Dashboard developed using Power BI to analyse employee attrition, workforce trends, job satisfaction, and key HR metrics.

## 🛠️ Tools Used
- Power BI
- Microsoft Excel
